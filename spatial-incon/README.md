# Spatial Inconsistency Project Website

Project page for **Multimodal Language Models Cannot Spot Spatial Inconsistencies**.
The layout follows the Nerfies publication template used by Gen2Seg. The story,
teaser, benchmark comparison, method, and control results follow the COLM poster.

Run a preview from the repository root:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/spatial-incon/`. The page links to the
[paper](https://arxiv.org/abs/2604.00799) and
[code](https://github.com/UCDvision/spatial-incon) for COLM 2026.
The teaser’s answer selection is implemented in `js/index.js`.

Template credit: [Nerfies](https://nerfies.github.io/),
[Gen2Seg](https://reachomk.github.io/gen2seg/), and
[Marigold](https://marigoldmonodepth.github.io/).
